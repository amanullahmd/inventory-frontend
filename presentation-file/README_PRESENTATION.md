## Key Highlights

### The Opportunity
- **66,000+** government primary schools
- **20.5 million** students
- **~500,000** staff across 8 divisions, 64 districts, 514 upazilas, 505 URCs

### The Challenge
- Manual, paper-based supply chain processes
- No real-time visibility across the network
- High risk of misuse and financial loss
- Inefficient procurement based on guesswork
- Massive officer workload (80-90% administrative burden)

## Technology Stack

### Frontend
- Next.js 16 (React framework)
- TypeScript (type-safe development)
- Tailwind CSS (responsive styling)
- Bangla/English UI (localized)
- Progressive Web App (PWA - works offline)

### Backend
- Spring Boot 3.x (enterprise Java framework)
- RESTful APIs (clean architecture)
- Microservices (modular, scalable)
- JWT Authentication (secure)
- RBAC + FBAC (granular access control)

### Database
- PostgreSQL (reliable, ACID-compliant)
- Redis (in-memory caching)
- Elasticsearch (search & analytics)

### Infrastructure
- Docker & Kubernetes (containerization)
- Load Balancing (Nginx/HAProxy)
- Cloud-Ready (AWS, Azure, or private DC)
- Backup & Disaster Recovery (automated)
